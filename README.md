# Vercodex Lead Finder

Vercodex için potansiyel müşteri bulma ve takip arayüzünün ilk sürümü.

## Özellikler

- Şehir ve kategori filtresi
- İşletme adı, ilçe veya Instagram ile arama
- Web sitesi olmayanları filtreleme
- Lead durumunu tek tıkla ilerletme
- Aday ve dönüşüm sayaçları
- Mobil uyumlu arayüz
- İlk sürümde örnek veri

## Çalıştırma

Node.js 18+ önerilir.

    npm install
    npm run dev

## Sonraki adım

Google Places API entegrasyonu ile gerçek işletme sonuçlarının alınması ve uygun Instagram araştırma akışının eklenmesi.
